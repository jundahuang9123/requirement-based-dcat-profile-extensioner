# W3C DCAT versions (all kept)

One directory per W3C DCAT version: `dcat-2014/`, `dcat-2/`, `dcat-3/`. Each holds:

- `dcat.ttl`: the namespace document of that version, **unmodified** (from `w3c/dxwg`);
- `spec.html`: the specification text, **unmodified**. `dcat-3/spec-pr.html` holds the Proposed
  Recommendation of 2024-06-13, the DCAT state DCAT-AP 3.0.0 was released on.

Two files are generated by `scripts/build_dcat_versions.py` from those (do not edit by hand):

- `model.json`: the classes of the specification and, per class, the properties it lists, with
  definition, range, domain and usage note;
- `history.json`: per DCAT term, the versions that define it, deprecate it and introduced it.

`versions.yaml` names the source repository, commit, path and SHA-256 of every file, and the W3C
status history of each version. Which version a DCAT-AP release builds on is stated in that
release's `data/base-profiles/<id>/profile.yaml` (`dcat_basis`). See `docs/dcat-versions.md`.
